# hooks_config.md — 6フック型テンプレ（週次分析で自動更新）

TikTok v4パイプラインの6フック型をThreadsテキスト1行目用に翻訳したもの。
投稿は必ずこのいずれかの型で開始する。週次分析の結果で型の重みを更新する。

## 型一覧（weight = 生成時の採用比率、週次で更新）

### 1. 価格ショック（weight: 25）
数字を先頭に。楽天のクーポン・ポイント還元と相性最強。
- 「◯◯円だと思ってたやつ、クーポンで1,980円になってた」
- 「これが3,000円以下って価格設定バグってる」

### 2. 社会的証明（weight: 20）
レビュー件数・ランキングを事実として提示。
- 「レビュー◯万件って何ごと？と思って見に行った」
- 「楽天◯◯ランキング1位、理由がレビュー読んだら分かった」

### 3. 悩み言い当て（weight: 20）
ターゲットの悩みを1行で言語化→本文で商品へ。
- 「夕方の顔のくすみ、照明のせいじゃなかった」
- 「寝ても取れないむくみ、あれ靴のサイズ変わるよね」

### 4. 時短・簡便（weight: 15）
persona最優先軸。「ながら」「◯分」を入れる。
- 「寝かしつけ後の5分でできるケア、これしか続かなかった」

### 5. 意外性（weight: 10）
常識の逆張り・用途の意外性。
- 「◯◯用に買ったのに、△△に使うのが正解だった（レビュー談）」

### 6. ビフォアフ示唆（weight: 10）⚠️コンプラ最注意
断定禁止。「レビューでは」「個人の感想」を必ず経由。
- 「レビュー欄のビフォーアフター報告、読み物として面白すぎる」

## 本文の型（フックの後）

- レビュー由来の購買理由を2つ（「◯◯という声」「△△で買った人が多い」）
- 使用シーン1つ（personaの生活文脈に置く）
- 捏造禁止：自分が使った体験のように書かない

## CTA型

- 「詳細とクーポンはこちら→（リンク）」
- 「レビュー◯件、読んでから決めても遅くない→（リンク）」
- 末尾に #PR（compliance_check.pyが自動付与・検査）

---

### 7. 比較・買い替え（weight: 0 ／比較モード専用・日次の抽選対象外）
`config/comparison_template.md` で使う専用型。日次の単品生成では選ばない。
入力は `config/my_products.md`（実際に買い替えた商品）のみ。
- 「◯◯を3年で2回買い替えて、やっと落ち着いた」
- 「前のやつの何が嫌で乗り換えたか、先に書いておく」

weightが0なのは、この型が**週1本・スレッド型**の別ルートだから。
週次分析の型別ランキングには「比較」として計上するが、重み更新の対象外にする
（本数が少なく、平均値がノイズになるため）。
