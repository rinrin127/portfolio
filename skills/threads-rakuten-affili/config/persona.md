# persona.md — ターゲット定義（初回チューニング必須）

投稿生成・商品選定の「自分も欲しいと思うか」判定はこのファイルを基準にする。
初回セットアップ時にりんりんと1往復で調整すること。

## メインターゲット（初期仮説）

- 30〜40代女性、子育て中で自分の時間が少ない
- 美容・健康に関心はあるが、高額商品や手間のかかるケアは続かない
- 楽天経済圏ユーザー（ポイント意識が高い、お買い物マラソン参加）
- スマホでThreads/Instagramを隙間時間に見る

## 刺さる訴求軸（優先順）

1. 時短・ながらケア（「子ども寝かしつけ後の5分」）
2. コスパ・ポイント還元（「クーポンで実質◯円」）
3. レビューの多さ＝失敗しない安心感
4. 季節性（紫外線、乾燥、むくみ等の今の悩み）

## 刺さらないもの（選定から除外）

- 高級ライン（1万円超）／手順が多いケア用品
- 若年向けトレンドコスメ（ターゲット年齢と不一致）
- 効果を大げさに謳う系（コンプラ以前に信頼を損なう）

## 「自分も欲しいか」チェック（商品選定時にAIが自問する3問）

1. このターゲットが商品ページを見て30秒で価値が分かるか
2. 価格が「試してみようかな」の範囲か（衝動買い帯：1,500〜6,000円）
3. レビューに「買った理由」が言語化されているか（＝投稿の素材になるか）
