# my_products.md — 買い替え履歴メモ（比較モードの唯一の入力）

比較モードはこのファイルだけを入力にする。楽天APIの人気商品ではなく、
**りんりんが実際に買い替えた商品**を起点にする。理由は2つ。

1. 「前に何を使っていて、なぜ変えたか」は買った人にしか書けない。比較投稿で
   いちばん読まれるのはここで、AIには絶対に生成できない（＝捏造禁止ルールと両立する）
2. 消耗品は無くなればまた買う。半年後に同じ投稿がもう一度効く

## 書き方（りんりんが1商品3行だけ書く）

楽天アプリの購入履歴を開いて、**2回以上買った / 別のものに買い替えた**商品を選ぶ。
1回しか買っていないものは書かない（比較の材料にならない）。

```
## <商品カテゴリ名>
- 今: <今使っている商品名>
- 前: <前に使っていた商品名>
- 理由: <乗り換えた理由を1行。不満だった点を具体的に>
```

理由は「なんとなく」ではなく、**動作で書く**と投稿の材料になる。
悪い例:「こっちのほうが良かった」／良い例:「詰め替えの口が硬くて毎回こぼしてた」

## 選定チェック（AIが商品を選ぶときの3問）

1. 買う前に複数商品で迷う人が多いか（＝検索されるか）
2. 定期的に買い替えが発生するか（＝半年後にもう一度読まれるか）
3. 「理由」に具体的な不満が書かれているか（＝体験プレースホルダが埋まるか）

3つとも満たすものを1つだけ選ぶ。満たすものが無ければ**比較モードを実行しない**
（通常の単品モードに落とす）。無理に比較を作らない。

## 楽天との相性メモ

楽天の成果はクリックから24時間以内にかごへ入り、89日以内に購入完了で対象になる。
かごに入った商品が紹介商品と別でも対象になり得るため、**単価より「クリック数」を稼ぐほうが効く**。
また1商品あたりの成果報酬には上限があるので、高額商品を狙う意味は薄い。
→ 狙うのは **買い替えが起きる・ふつうの価格帯（1,500〜6,000円）の消耗品**。
（条件は変更されうるので、料率・上限は公式ページで都度確認する）
