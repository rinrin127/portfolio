# skills/ — Claudeスキルの管理コピー

claude.ai に登録して使っているスキルの**バージョン管理用の原本**です。
サイトのビルド（`npm run build`）とは無関係で、`content/` も `index.html` も参照しません。

## claude.ai への反映手順

claude.ai のスキルは、このリポジトリと自動では同期されません。
ここで更新したら、claude.ai の「スキル」画面で該当スキルを開き、
変更したファイルを差し替えてください（新規ファイルは追加）。

反映が必要なファイルは、そのコミットの差分がそのまま一覧になります。

```bash
git log --stat -1 -- skills/
```
