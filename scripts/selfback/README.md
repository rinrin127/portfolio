# A8.net セルフバック 半自動チェッカー

A8.netの「セルフバック」案件を定期的にチェックし、条件に合う案件（報酬額でふるい、危険なジャンルは除外）を
一覧化・タブで開いた状態にするツールです。**申し込みボタンを押すところまでは自動化していません。**

## これは何をするツールか

1. ブラウザを自動で開く
2. **初回だけ、自分の目でA8.netにログインする**（ID/パスワードはこのツールに一切渡しません。2段階認証もそのまま画面で完了できます）
3. ログイン状態を `state/` に保存し、2回目以降は自動で再利用する
4. `config.json` で指定したセルフバック一覧ページを開いて、案件名・報酬額・リンクを読み取る
5. 除外キーワード（デフォルトでクレジットカード・ローン・FX・投資などを除外）と最低報酬額でふるいにかける
6. 報酬額が高い順に並べ、`reports/` にMarkdownで一覧を書き出す
7. 上位の案件ページをブラウザのタブで開いた状態にする → **あとは自分の目で確認して、自分でクリックするだけ**

## なぜ「申し込みまで」自動化しないのか

- A8.netを含むASPは、ログインを伴う自動操作（bot的なアクセス）を規約で禁止していることが多く、
  発覚するとアカウント停止・報酬没収のリスクがあります。
- セルフバック案件（特にクレジットカード発行・ローン・FX口座開設など）は、実際の個人情報を使った
  本物の契約・審査申込です。自動送信すると、意図しない契約や信用情報への影響が発生し得ます。

このツールは「案件を探して開くところまで」を自動化し、**契約・登録という重い意思決定は必ず自分の手で行う**
という前提で設計しています。この前提を変えて完全自動送信化することはおすすめしません。

## セットアップ

```bash
npm install
npx playwright install chromium

cp scripts/selfback/config.example.json scripts/selfback/config.json
```

`scripts/selfback/config.json` を開いて、少なくとも `selfbackUrl` を設定してください。
（A8.netに手動でログイン → 上部メニューの「セルフバック」を開く → そのときのURLを貼る）

## 使い方

初回・動作確認時は `--debug` 付きで実行してください。ページのHTMLが `reports/debug-page.html` に
保存されるので、案件がちゃんと拾えているか確認できます。

```bash
npm run selfback:debug
```

- ブラウザが開くので、まだログインしていなければ画面上でログインし、ターミナルでEnterを押す
- 拾えた案件数・条件に合った案件数がターミナルに表示される
- `reports/` に案件一覧（Markdown）が出力される
- 条件に合う案件が上位からタブで開かれる

うまく案件が拾えない場合は、`config.json` の `rewardPattern`（報酬額の書式）を
実際のページの表記に合わせて調整してください。

2回目以降はログイン不要（セッションを再利用）なので、そのまま実行できます。

```bash
npm run selfback
```

## 設定項目（config.json）

| 項目 | 説明 |
| --- | --- |
| `selfbackUrl` | セルフバック案件一覧ページのURL（必須） |
| `minReward` | この金額（円）未満の案件は除外 |
| `excludeKeywords` | 案件名・周辺テキストにこの単語を含む案件は除外（デフォルトでカード・ローン・FF等を除外） |
| `completedMarkers` | 「獲得済」等、すでに完了した案件を示す単語（該当する案件は除外） |
| `maxOpenTabs` | 一度に開くタブの上限 |
| `loggedInMarkerText` | ログイン済みかどうかを判定するための画面上の文言 |

## 注意事項

- `config.json` と `state/`（ログインセッション）、`reports/`（案件レポート）は `.gitignore` 済みで、
  リポジトリにはコミットされません。このリポジトリは公開ポートフォリオサイトなので、絶対にコミットしないでください。
- 定期実行する場合は、GitHub ActionsのようなCI上ではなく、**自分のPC上でcron/タスクスケジューラから実行する**
  ことを推奨します（ログインセッションを外部サービスに渡さないため）。
- `excludeKeywords` を編集してクレジットカード等を対象に含める場合は、実際に契約してよい内容かを
  案件ページで必ず自分の目で確認してからにしてください。
